# 盘卡模板（intake.py 输入格式）

> 用途：手上有一份**已经排好/别处编排好的盘**时，把它填进这张卡，
> 一次喂给 `scripts/intake.py`，四步机械层（排盘 / 神煞 / 五行 / 调候）一次跑完。
>
> 跑法：
> ```bash
> python3 scripts/intake.py --card 我的盘.md
> ```
>
> ⚠️ 本卡**只进机械层**，不进解读。断语与报告规格见 `references/delivery-spec.md`。

---

## 填法（复制下面这段，改掉内容即可）

```
四柱：甲子 丙寅 戊午 庚申
性别：男
来源：示例假盘（非真实命盘）
```

- **四柱**（**唯一必填**）：年、月、日、时四柱，空格 / 逗号 / 顿号分隔都行。
- **性别**（**必填**）：男 / 女。影响大运顺逆与元辰等性别相关神煞。
- **来源**（可选）：如"原文直给"、"真太阳时校正后"、"别处排盘"。
  会印进报告的输入区，便于回溯。
- **出生**（可选）：`1990-05-15 12:00`。给了就会额外做一次公历反查，
  用于**核对四柱与公历是否自洽**（例：公历反推不出该日柱时会有警告）。

## 完整示例（含出生信息，用于自洽校验）

```
四柱：甲子 丙寅 戊午 庚申
性别：男
来源：示例假盘（非真实命盘）
出生：1990-05-15 12:00
```

跑法二选一：

```bash
# 用盘卡
python3 scripts/intake.py --card 盘卡示例.md

# 不用盘卡，直接命令行给
python3 scripts/intake.py --pillars 甲子,丙寅,戊午,庚申 --sex 男
```

## 常见情况

| 情况 | 怎么填 |
|---|---|
| **只有四柱，没有公历生日** | 只填「四柱」+「性别」。大运**不出起运年龄**（四柱不含出生日），只列 10 步干支 —— 这是正确行为，不是缺漏 |
| **四柱 + 公历生日都有** | 两行都填。跑完请**核对**：`pai_pan.py --solar`（出生信息模式）排出的四柱应与卡上一致；不一致会有警告，须先解决再断 |
| **四柱与公历对不上** | **保留四柱原样**（`--pillars` 直输），把冲突如实报出。**不要**拿公历去"纠正"四柱 —— 那会造出一个假的起运年龄和假的流年表 |
| **时辰未知** | 时柱写「未知」不行 —— 本卡要求四柱齐全。时辰未知请走 `pai_pan.py --solar … --sex …`（不带时柱），只做六字 |
