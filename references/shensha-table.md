# 神煞表

神煞只是辅助，不能单独论命。论命以日主旺衰、格局、用神为主，神煞只作旁证。

本表是本仓库**唯一神煞口径**，与 `scripts/pai_pan.py` 的计算规则完全一致。排盘只输出命局实际命中的条目；时柱未知时，不得用时柱凑神煞。

> 🔌 **接线说明（2026-10-04）**：本表下方「机器可读定义」块是**唯一执行口径**，
> `scripts/shensha_engine.py` 直接解析它运行 —— **改表即改行为，不需要改代码**。
> 上半部分的人类可读描述**仅作解释**，若与机器块冲突，**以机器块为准**。

## 吉

### 天乙贵人

- **名称**：天乙贵人
- **吉凶**：吉
- **查法**：按**年干或日干**查四柱**地支**。年干、日干各自对应的贵人支，出现在年支、月支、日支、时支则见（时柱未知不计时支）。
- **口诀或查表**：
  - 甲戊 → 丑未
  - 乙己 → 子申
  - 丙丁 → 亥酉
  - 壬癸 → 卯巳
  - 庚 → 丑未寅午（「甲戊庚牛羊」与「庚辛逢虎马」取并集）
  - 辛 → 寅午

### 天德

- **名称**：天德
- **吉凶**：吉

**口径备注**：

1. **将星/华盖/驿马/劫煞/灾煞/亡神/桃花**：本表按**年支或日支**双起（`year_zhi+day_zhi`），两法结果**并集输出**并各自标注来源 —— 这与 `huofa_layer.py` 原来"逐支扫描、两法都列"的做法一致。
2. **孤辰/寡宿**：**仅按年支**起（`anchor: year_zhi`），不用日支。
3. **天德**：`target: mixed` —— 天德值可能是天干或地支，需按字在 `GAN` 还是 `ZHI` 中判断落在哪一层。
4. **元辰**：唯一 `sex_dependent: true` 的神煞。阳年＝年干属甲丙戊庚壬；按"阳年男/阴年女"与"阴年男/阳年女"分两表。
5. **空亡**：按日柱**旬首**查（`mode: xun`），不是按日支。
6. ⚠️ **本块是唯一执行口径**，与上方人类可读描述冲突时以本块为准。
