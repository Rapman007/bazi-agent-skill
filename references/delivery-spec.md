# 交付规格 v3（看盘报告）

> **本文件是"报告怎么写"的唯一权威规格。**
> **出任何一份完整看盘报告前必读。**

---

## 〇、四条总纲

1. **八字不是成绩单，是体检报告。**
   成绩单告诉你考了多少分 —— **它做不到**。体检报告告诉你哪里弱、该防什么 —— **它做得到。**

2. **不打档、不排名、不评高低。**
   实测：拿 10 个名人盘与 10 个普通盘同规格排榜 ⇒ **分不开"名人"与"普通人"**。
   ⇒ **高低定不了，就别定。**

3. **只回答「结构」，不回答「量级」。**

4. **只列问题不给方案 ＝ 废纸。**
   每一处弱项都必须落成 **课题 ＋ 方案 ＋ 参考 ＋ 劝导**。

## 一、读法：地形 / 天气 / 修

| 层 | 比喻 | 做什么 |
|---|---|---|
| **原局** | **地形图**（哪里低洼、哪里陡、哪里是硬岩） | 画结构 |
| **大运** | **天气表 ＋ 场**（哪段多雨、哪段干旱；**外面在刮什么风**） | 报节奏 |
| **修** | **施工图**（这副地形上房子该怎么盖） | 给方案 |

> 🔴 **大运是「筛选器／激活器」，不是「编码器」。**
> 它**把原局里已有的那一处暴露出来**；**原局里没有的，它勾不出来。**
> 同一年出生的人走同一条大运 —— 它不因人而异。
>
> 🆕 **补充（v2）**：**"筛选器"只描述"场 → 心"这一条线，不是大运的全部身份。**
> 大运的完整形态是 **「天地之间能量场的变化」**，含**三条传导线**：
> **场 → 事**（周围事物的变化）｜**场 → 心**（心智发展：哪一面被勾出来）｜**心 → 行**（行为之间的规律）。
> ⚠️ **边界**：只描述"**这个场里哪类事更容易发生**"，**不得写成"大运决定某事件发生"**。
> 依据：`模型-原局与大运-地形与天气` v2（**本 skill 不引用任何外部路径，口径见本文件**）。

## 二-补、🩸 §〇-狠 · 狠话（**每盘必有的一句**）

> **起因**（定稿依据）：「**你并没有给他一句狠话。……你把"狠话"这一条写到 skill 里面。**」
> **性质**：**交付规格，默认开启** —— 不需要授权，不破任何一道阀。
> ⚠️ **与 `blunt-mode.md`（绝对断模式）是两件东西，别混。** 区别见下表。

### 一句话

> ## **每盘必须有一句狠话。它写"这副牌哪儿疼"，不写"这个人怎么样"。**

### 它与「绝对断模式」的区别（**先分清，再动手**）

| | **§〇-狠（本格）** | **`blunt-mode` 绝对断模式** |
|---|---|---|
| **开关** | ✅ **默认开**（每盘必出） | 🔴 默认关，**须用户明确授权** |
| **破阀** | **一道都不破** | 破"禁量级"＋"禁人格判词"两道 |
| **写什么** | **结构与代价** —— 这副牌最疼的那一处 | 量级（能到多高）＋ 人格判词（是什么人） |
| **范围** | **一格（一句话）** | **整档** |
| **对第三人** | **同样要出**（不触阀） | 须**单独**授权，且三条限制不可豁免 |

> **🔑 一句话判据**：**这句话是在说「这副牌哪儿疼」，还是在说「这个人值多少 / 是什么人」？**
> **前者 ＝ 本格，默认出；后者 ＝ 须解阀。**

### 🔴 三条判据（缺一不算狠话）

| # | 判据 | 反面（不合格的样子） |
|---|---|---|
| **1** | **今天就打得响** | 到期日在十年之后的断言 —— **不痛，就不狠** |
| **2** | **当事人不爱听** | 落在当事人**已经认同**的框里 ⇒ 那只是"把他自己说过的话，换更重的语气重复一遍" |
| **3** | **有机制可指** | 追不到具体的干支／十神／宫位 ⇒ 那是**感觉**，不是判读 |

> ⚠️ **第 2 条最常失手**：越是"顺着他心意写的绝对句"，越像狠话，其实越软。
> **出档前自问一句：这句是我从盘上逼出来的，还是他本来就想听的？**

### 写法硬规

| # | 规 |
|---|---|
| **1** | **≤40 字，一句。** 不拆成两句，不加副标题，不加箭头 |
| **2** | **禁用词**：可能／或许／不排除／未必／两说并存／某种程度上／多少有点 |
| **3** | **句尾不许缓冲** —— 不接"但这不代表…""只要愿意改…""以上倾向仅供参考" |
| **4** | **不许在本格内加免责** —— 免责统一归 §十 |
| **5** | **位置固定**：紧跟 §〇 一句话断语，**独立成格**；**不得塞进总段语里被稀释** |
| **6** | **必须能反查回 A 轨（理法）** —— 与取象同规，反查不到 ⇒ 删 |

### 狠话 ≠ 骂人（**边界表**）

| ✅ 允许（说结构与代价） | ⛔ 不许（说人） |
|---|---|
| "这条路一直开着，但他从来没走上去过" | "他是个逃避的人" |
| "他攒下的东西，永远比交出去的少" | "他不靠谱" |
| "那扇门一直是空的" | "他没什么靠山"（＝人格判断） |
| "他会一直准备，直到机会不再需要他" | "他成不了事" |

> **对外盘（本人不在场）同样要出狠话** —— 因为它不触"禁量级""禁人格判词"两道阀。
> **人格判词仍然只有 `blunt-mode` 授权后才可出**，且须单独授权。

### 示例（**假盘 · 一律不举真实案例**）

> 某假盘：日主无根、财星虚透、食伤被合。
>
> - ✅ **合格**：「**他这辈子赚到的钱，都是别人先替他拿着。**」
>   （机制可指：财虚透＝财不落手；食伤被合＝自己造钱的口被堵）
> - ❌ **不合格**（缓冲）：「他的财运算不上好，可能赚钱上会有点辛苦，不过这也可以靠努力改善。」
> - ❌ **不合格**（判人）：「他是个守不住钱的人。」
> - ❌ **不合格**（打不响）：「他在 2035 年前后会遇到一次财务危机。」

### 出档前自检（**逐条过，缺一不合格**）

- [ ] **有狠话吗？**（没有 ⇒ 本档不合格）
- [ ] 三条判据（今天打得响／不爱听／有机制）都过了吗？
- [ ] 这句说的是**"结构疼"**，还是**"人不行"**？（后者 ⇒ 降级重写）
- [ ] 它是不是**当事人本来就认的**那一批？（是 ⇒ 重写）
- [ ] **有没有在紧接着的下一段被冲淡？**（有 ⇒ 挪出来、独立置顶）

## 二-补二、🌬 §〇-C′ · 多盘合盘的「象」与「气」（**合盘专属 · 必出**）

> **起因**（定稿依据）：「**原本在其他的地方你的说法是非常活的，但是一到合盘这里就变死了 —— 没有气和生肖类比那些、象什么的了，直接就是用典籍。**」
>
> ⚠️ **这与同日上午 §〇-F 活法层的起因是同一句批评**（"你那个一点都不活，是死的"）——
> 那次批的是**单盘**，这次批的是**合盘**。
> ⇒ ## **活法层（象／气／联想）不是单盘的特权，合盘同样必须出。**

### 🔴 合盘最容易犯的错（**一句话**）

> ## **把两个人的"单盘象"各抄一遍、并排放着 ⇒ 那还是死的。**
> ## **合盘的象，画的必须是「关系」，不是「两个人的简介并列」。**

### 核心判据

| | 单盘 §〇-C | **合盘 §〇-C′** |
|---|---|---|
| **取象** | 一个盘上的一个字 → 像什么 | **两个盘各自的"物象"** → 放在一起像什么 |
| **成象** | 把几个象拼成**一个画面** | 把两个物象**放进同一个画面**（谁浇谁／谁烤谁／谁堵谁／谁串谁） |
| **落象** | 第三人能观察到的样子 | **这段关系**在第三人眼里能看见的样子 |

### 四步（照做）

| # | 步 | 硬规 |
|---|---|---|
| **1** | **各出一句物象** | 每盘一句，必须**可追溯到具体干支**（例："一潭冬天的水" ← 壬水生子月＋双刃） |
| **2** | **找"撞点"** | 合／冲／刑／害／共享支／用神互忌 —— **把它读成一个"动作"**（浇·烤·堵·串·抽·搅） |
| **3** | **拼成一个画面** | 🔴 **两人必须在同一场景里**，不得写成两段；画面自洽；**不许加两个盘都没有的东西**；**一句话里不许出现未来** |
| **4** | **落象** | 必须写成"你**会看到**……"，第三人可观察；**不是"他心里……"** |

### 🔴 五条禁则

| # | 禁 |
|---|---|
| **1** | **禁用万能句** —— "既互补又有摩擦""既熟悉又陌生""缘分深浅" |
| **2** | **禁把两人的性格简介并排**（那叫人物表，不叫合盘） |
| **3** | **禁只写完地支关系表就交差** —— 表格是**理**，**必须有象** |
| **4** | **禁生僻比喻堆砌** —— 每个象都必须能反查回干支 |
| **5** | **禁凶象恐吓** —— 合盘涉真实关系，**画面可以冷，不可以咒** |

### 举例（**假盘 · 只示范句式**）

> 甲盘：冬水无火、出口只在一木 ｜ 乙盘：火四木零、一屋子热
>
> **取象**：甲 ＝ 一潭结着薄冰的水；乙 ＝ 一炉烧得很旺、但炉边没柴的火
>
> **成象**：
> > 一个屋子，一边是冰水，一边是旺火，**中间没有柴、也没有水渠** —— 热气过不来，冷水也浇不过去。
>
> **落象**：
> - 你**会看到**两个人各自都不弱，但**一件事从一个人手里递到另一个人手里时，总是"凉在中间"**
> - 你**会看到**他们之间不缺道理，**缺的是"暖气"**

> ⚠️ **注意最后一条落象的写法**：它说的是**这段关系**（"中间"），不是"甲是什么人、乙是什么人"。
> **这就是合盘象与单盘象的分界线。**

## 三、🔑 §〇-C 取象成象落象（**表达层核心**）

> 🛡️ **出象之前，先读 `references/xiang-guard.md`（取象铁律 · 三问防跳法）。**
> 本节讲的是**怎么写**；那份讲的是**什么不许写**（防"把符号的可能当成现实的判词"）。**两份配套，缺一不可。**

### 核心判据（一句话）

> ### **断「样子」，不断「事情」。**
> **判法：把句子改成现在时 —— 还成立 = 样子（可用）；不成立 = 事件（禁用）。**

| | 例 | 判 |
|---|---|---|
| **事件轴** | "她 2027 年会缺课三天" | 🔴 **越具体越坏**（伪精度） |
| **意象轴** | "像一根泡在冷水里的木头，长得出叶子，扎不下根" | ✅ **越具体越好**（说服力） |

**⇒ 两条规矩管的是不同的轴，不冲突。**

### 三段式

| 段 | 做什么 | 硬规 |
|---|---|---|
| **① 取象** | 盘上这一处**像**什么 | **每个象必须能追溯到具体干支/十神/宫位**；凭空长出来的象 = 编 |
| **② 成象** | 把几个象拼成**连贯画面** | **画面自洽**；**不许加盘上没有的东西**；**一句话里不许出现未来** |
| **③ 落象** | 对应**什么能看见的样子** | **必须是第三人也能观察到的**（"你会看到……"，不是"他心里……"） |

### 五条红线

1. **不出现未来**（除相对节奏节）
2. **每个象可追溯**
3. **画面自洽**
4. **落到可观察**
5. **不空转** —— 既不能追溯、又不能落成可观察 ⇒ **那是散文，不是判读**

### 🔴 双轨记账（**最重要的一条**）

> **取象是盲派的方法（象法）。子平给理法，盲派给象法 —— 两者可以融合，
> 但融完必须分账，否则读者分不清哪句能验、哪句只是画面。**

| 轨 | 内容 | 记账 |
|---|---|---|
| **A 轨 · 理法** | 格局、旺衰、十神关系、天气表 | **可入验证档，计分** |
| **B 轨 · 象法** | 取象、成象、落象 | **只做表达，不入验证档、不计分** |

**⇒ 硬规：每一句"象"，都要能反查到它上面站着的那个"理"。**
**反查不到 = 凭空长出来的象 = 删。**

> ⚠️ **自保提醒**：**象法天生有说服力**（画面感 = 可信度，与巴纳姆同一族心理机制）
> ⇒ **最容易骗到的是使用者本人**。看到一段象觉得"太对了"，**先回 A 轨问：这一段的理法依据是什么？**

## 三-补、🔑 §〇-D 十神方向表（**必出**）

> **依据 →** `references/shishen-xiang.md`（十神四问象表）
> **一句话**：**名字不改（对典籍），看法改（对现实）。**

### 格式（五方向逐行，缺一空着也要列）

| 方向 | 传统名 | **本盘的具体** | 条件下显什么象 | **所以你会看到** |
|---|---|---|---|---|
| **入** | 印（生我） | | | |
| **同** | 比劫（同我） | | | |
| **出** | 食伤（我生） | | | |
| **取** | 财（我克） | | | |
| **压** | 官杀（克我） | | | |

### 🔴 三条硬规

1. **"条件下显什么象"栏必须写强/中/弱（可加"虚""旺"）** —— 不许只写"有"

## 三-补二、🧭 §〇-F 活法层（**必出 · "死的"与"活的"的分界**）

> **依据 →** `references/huofa-layer.md`｜**脚本 →** `scripts/huofa_layer.py`（通用，任何盘都能跑）
>
> **起因**（定稿依据）：「**你那个一点都不活，是死的。没有看气，也没有看他整体的东西，也没有去联想。**」
>
> **根因**：格局线（格局→旺衰→用神→喜忌）**只能输出结构** ⇒ 必然"死"。本层换一条线，并把**锚从"日干"换成"年命/胎"**。

### 必跑脚本

```bash
python3 scripts/huofa_layer.py --pillars 甲子,丙寅,戊午,庚申 --lunar-month 11
```

### 六步（顺序固定）

| # | 步 | 硬规 |
|---|---|---|
| **1** | **四层气** | 天气／地气／身气／四周气。产出**一句画面**＋极纯或极杂。🔴 **必须分清「药」（等运调进来）与「出口」（盘里本来就有）** |
| **2** | **取象** | 每个象后面**必须接一句"它解释了旧法看不到的什么"**；接不上 ⇒ 删 |
| **3** | **纳音＋首尾** | 首尾同五行 ⇒ 该五行**在两头兑现、中段缺位**。⚠️ **纳音可以与正五行相反**（正五行无火 ≠ 纳音无火） |

| 级 | 时间尺度 |

## 五、🔑 §十三 结语（**每盘必写**）

### 固定三件

**① 一句定盘**：「这份盘是**起点**，不是终点。」

**② 机制（为什么"补充越多越准"）**
- 盘给的是**可能性的全表**；**哪一条在这个人身上是"活的"，只有现实能告诉你**
- 每补一条现实信息（一次事件／一个反馈／一个观察），判读就更准一分
- ⇒ **不是"盘越算越准"，是"盘 × 现实"越磨越准**

**③ 迭代邀请**

| 用户丢什么 | 怎么算准 |
|---|---|
| 一件具体发生的事（带时间） | 对上了 → 记 ✅ |
| 一条现实中的行为（带场景） | **对不上 → 记 ❌，并回头修判法**（不是修人） |
| **一个"你觉得不像"** | ⭐ **这条最值钱 —— 它能修判法** |

### 🔴 硬规

**不许把结语写成"以上仅供参考"。要写成"这是第一稿，请继续喂它"。**

## 八、🔑 判读规则（先行者补齐 · 2026-10-02 蒸馏段建业/陆致极/张仁丰所得）

> **来源**：外部先行者方法论调研（本次蒸馏所得）

### 补 1 · 🔴 **区分「存在」与「有效」**

> **原话**（段氏盲派）：「命局有冲，**不等于一定冲坏**；有合，**不等于一定化**；见墓，**不等于一律收藏**；天干虚透，**也不等于全无作用**。」

**⇒ 每条结构描述必须是「两句话」：**

| 句 | 内容 | 例 |
|---|---|---|
| **① 关系存在** | 只说机械事实（可复核） | "辰戌相冲" ／ "甲己同现天干" |
| **② 关系有效** | 加三个检查：**位置**（贴/隔）｜**根气**（有根/虚透）｜**是否被破**（冲散/争合） | "但辰戌相隔、戌无根 ⇒ **有效度低**" |

**🔴 硬规：不许跳过第①句直接写第②句。**

### 补 2 · 🔴 **取象必须过「四重交集」**

> **原话**：「同是财，可能是**金钱、货物、项目、妻缘、管理对象或现实欲望**；同是印，可能是**文书、学历、房屋、照护、单位、思想或母亲**。
> 具体取哪一象，**要由十神、宫位、干支本象和组合共同限定**。**象法不是凭灵感自由联想，而是多重信息的交集。**」

**⇒ 每个象必须过四重：**

| 重 | 问什么 |
|---|---|
| **① 十神** | 它在哪个方向（入/同/出/取/压） |
| **② 宫位** | 它在哪一柱（年＝早年/外部；月＝平台；日＝自身；月＝平台；时＝产出/晚景） |
| **③ 干支本象** | 这个字本身是什么物象 |
| **④ 组合** | 它跟谁在一起、被生还是被制 |

**🔴 四重交集才允许出象；任何一重说不出 ⇒ 这个象是自由联想 ⇒ 删。**
**⇒ 这条给「双轨记账」的 B 轨（象法）补上了质量标准。**

### 补 3 · **结构状态三条（改造版 · 只描述不打分）**

| 改造后 | 问什么（**只描述**） | 例 |
|---|---|---|
| **通不通**（原"流通"） | 能量**走得通吗**，卡在哪 | "水有出口（甲木）⇒ **通**" |
| **纯不纯**（原"清纯"） | 主结构**是一条线还是几股力互抵** | "四丙一势 ⇒ **纯**但无根" |
