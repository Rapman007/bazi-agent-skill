# 十线地图与统一结构

> **来源**：2026-10-03 十个独立 agent（每线一个）深挖 + 十条串联轴咬合 + 五轮迭代 + 自查。
> 本图独立成文，不依赖任何外部档。
>
> **本文件的作用**：给断盘提供一张**坐标系**。看到任何一条断法，先用它定位 —— 不用从头学一遍。

---

## 一、七步管道（所有术数共用）

```
① 采样 → ② 切块 → ③ 贴标 → ④ 定锚 → ⑤ 运算 → ⑥ 读数 → ⑦ 定期
```

| 步 | 做什么 |
|---|---|
| ① 采样 | 取一个时间点（或一个空间面、一个当下瞬间） |
| ② 切块 | 切成有限个格子（四柱／十二宫／九宫／部位） |
| ③ 贴标 | 给格子挂属性（五行／十神／星曜／卦象／纳音／神煞） |
| ④ 定锚 | **把「我」钉在某一格** |
| ⑤ 运算 | 格子之间跑固定关系表 |
| ⑥ 读数 | 把关系结果翻译成人事 |
| ⑦ 定期 | 把结论锚回时间轴 |

**⇒ 十套体系的分歧只有三处（其余七步完全一致）：**
1. **锚钉在哪**（＝ M1 起点）
2. **用哪族贴标表**（＝ M2 表族）
3. **允不允许外部取数**（＝ ①采样的重入权限）

---

## 二、三处分歧的具体取值

### 分歧① 锚（"我"是谁）

| 体系 | 锚 |
|---|---|
| 子平八字／盲派／四象神兽格 | **日干** |
| 古法禄命（纳音·胎元） | **年柱纳音** |
| 紫微斗数 | **命宫**（只吃月＋时，与日干无关） |
| 六爻 | **世爻** |
| 梅花易数／外应 | **体卦** |
| 河洛理数 | **元堂爻** |
| 神数（铁板/邵子） | **无锚**（四柱是索引） |
| 相术 | **脸和手本身**（空间锚） |

**锚只分三类：时间锚／关系锚／空间锚。**
**🔴 选锚判据**：
- 问"我一生结构" → 时间锚
- 问"此一事成败" → 关系锚
- 问"此人此刻状态" → 空间锚

> **⇒ 同一个八字，换一个锚，整套结论就换一套。**
> **"同盘三派三种用神"不是谁算错了 —— 是换了锚。**

### 分歧② 贴标表 —— **不是一张表，是三族**

| 族 | 生成元 | 例 |
|---|---|---|
| **干支族** | 阴阳2 × 五行5 × 十干十二支 | 十神、藏干、神煞 |
| **卦象族** | 阴阳2 × 三爻（2³＝8） | 八卦、六十四卦、六亲 |
| **命名族** | 五音 × 十二律 / 纯文本 | 纳音、条文 |

**🔴 族间只有"方位↔五行"一座桥（后天八卦），没有通用翻译函子。**
- **翻不过去的典型**：纳音五行 ↔ 正五行。（甲木＋子水 → 海中金，五行全变；30 格 vs 60 格，基数不同）
- **"羊刃＝劫财帝旺"也不成立** —— 羊刃是**阳干**帝旺（甲见卯、庚见酉），乙见寅、辛见申并不重合。
- ⚠️ 网上流传的"十神↔紫微星对应百分比表"来自商业站，**无方法学，不可用**。

> **⇒ 所谓"共用零件"是共用了原料（干支、五行、方位），不是共用了翻译器。**

### 分歧③ 采样重入权限

**统一动作：共时截帧** —— 在某个瞬间 t 对全域符号状态截一帧，用固定符号表编码。
**外部取数 ＝ 允许这个动作在 t ≠ 出生时重开一次。**

| 型 | 体系 | 做什么 | 能答什么 |
|---|---|---|---|
| **换锚型** | 外应、奇门、六壬 | 锚挪到**问事瞬间** | ✅ **能答"这件事"** |
| **提精度型** | 铁板考时定刻 | 锚仍在出生瞬间，只把出生帧从"时辰"细化到"刻分" | ❌ 答的仍是"这个人" |
| **本体采样** | 相术气色 | 采眼下这个人的即时帧 | 答"此人此刻" |

**🔴 判据（两条）**：
- **判据一**：新帧是否携带"**不由出生帧决定**"的信息？（互信息 < 1）
  - 大运流年 **不算**（完全由出生帧决定）｜胎元 **不算**（确定性反推）
- **判据二**：**采样者必须不可控**。（澄心／随机／事实淘汰 ＝ 同一原则的三种实现）

**为什么只有"换锚型"能答具体事**：一件具体的事本身就是某个 t 的事件帧。只有让采样时刻与事件帧**重合**，符号帧才与事件帧同帧耦合。出生帧与任何具体事件都不重合 ⇒ 只能给"跨事件恒定的结构"（命），给不了"事"。

## 三、⚠️ 全局负债：整个体系的唯一杠杆在第①步

三条独立路径撞在同一个点：
- **失效**：①采样与⑥读数之间**缺一条对偶线**
- **反馈**：**没有任何一条线的反馈接在⑥之后并指向未来**
- **外部取数**：外部取数就是让①可重入

> **历史旁证**：陈素庵、任铁樵砍掉了无反馈的第③步（弃神煞、弃纳音），**但没人去补第①步** —— 所以砍完换一派照旧复发。
> **⇒ 命理史上所有"改良"为什么都不成功：全在③⑤⑥做手术，没人动①。**

## 四、四条不变量

| # | 不变量 |
|---|---|
| **1** | **机械层与判读层的切口永远在同一位置**：符号→符号可复算；**现实→符号、符号→人事靠人**。⇒ **断语的信息量全部来自"靠人"那一段** |
| **2** | **总公理**：「一个时间瞬间的差异，可被固定符号表完整、一一对应地编码，且编码差异对应现实差异」 |
| **3** | **"准"只在有反馈信号的维度上成立** |
| **4** | **格数不是硬规则**（紫微星曜 14→159、神煞 120→15 自由增减）；硬的只有"必须是有限个可分辨的格子" |

### 不变量 3 的操作化（**断盘时最有用的一条**）

> **命题**：某条线在某个维度上的预测力上限 ＝ **该维度上反馈信号的可用度 A**

**A ＝ 四要素之积**（各 0/1）：
1. 第三方可独立查证（不是"我记得"）
2. 可二值（是／否）
3. 反馈滞后 < 一个决策周期
4. 核验者不知预测内容

**用 Δ ＝ P(hit) − P(base)，不用绝对准确率。**

**已知印证**（郭耀宗 325 例自测）：六亲类（A 高）克父 85%／克母 90%／克妻 90%；时序类（A 低）结婚时间 66%／兄弟数 72%。
⇒ **不是线的问题，是维度的问题。**

**铁板神数的极端例证**："过往极准、未来模糊" = 条文库 821 条条件句中 **661 条（80.5%）挂在六亲**（当场可核）；而流年条文中 **76.67% 无任何时间坐标**（"行乐度流年，万事得安然"）。

**⇒ 断盘时的用法**：
- **A 高的维度**（可核的既有事实、二值的行为命题）→ **可以出断语、可以封存计分**
- **A 低的维度**（未来时序、连续量、无语境可核）→ **只描述、只做相对节奏，不出具体断语**

## 五、⚠️ 四组内部矛盾（术数自己就没合上的缝）

> **用途**：可以拿它们**直接筛掉一半的"大师说"**。这些不是外部批评，是体系内部的冲突。

| # | 矛盾 | 说明 |
|---|---|---|
| **A** | **出生锁终身 vs 行为可改写读数** | 裴度还带把冲突写在明面上：同一副骨相，先判"不贵则饿死"，后判"有阴德到了你身"。**两条不可同真** |
| **B** | **生克是唯一闭合环 vs 表族并存** | 相胜（邹衍五德终始）与相生（董仲舒）起点不同 —— **汉人正是靠换环来改朝换代合法性。历史事实是：环被换过** |
| **C** | **锚的唯一性 vs 一盘多锚** | 合局可同时成立多个局 ＝ 同时有多个锚 |
| **D** | **锁必须盘内在先 vs 再截一帧** | **外应的锁不在盘内，在占卜现场** ⇒ 只能说"内源触发可统一" |

## 六、断盘时的使用规程

### 出报告前先定位三件事

1. **这份盘用的是哪个锚？**（八字 = 日干）
2. **这份盘属于哪一族贴标表？**（干支族）
3. **这份盘允不允许外部取数？**（八字 = **不允许**，采样只一次）

### 由此得到三条硬约束

| 约束 | 内容 |
|---|---|
| **① 不要说"八字看出来某件具体事"** | 八字是**封闭采样**（没有外部取数）⇒ 结构上给不了"具体哪件事"。要问具体事 → 走奇门/六壬占测局 |
| **② A 低的维度不要出断语** | 见 §四 不变量 3 |
| **③ 换系统 ≠ 加强证据** | 八字与紫微**同配置**（都是出生帧一次、封闭），交叉验证**信息量低**。真正有信息量的是**跨配置**：八字 × 相术、八字 × 外应 |

### §〇-E 十线定位（**报告新增节 · 放在 §〇-D 之后、§一 之前**）

出报告时给出这一小表，让使用者知道这份结论站在哪条线上、边界在哪：

| 项 | 本盘取值 |
|---|---|
| 锚 | 日干（时间锚） |
| 贴标表 | 干支族（十神／五行／藏干／神煞） |
| 采样重入权限 | **无**（只在出生瞬间采一次） |
| ⇒ 能答 | 结构、倾向、弱项、相对节奏、决策盲区 |
| ⇒ 不能答 | 具体事件、量级、寿数、无判法线的事 |

## 七、⚠️ 本框架的自查（诚实记录，使用时保留）

**① 结构上被迫的**：①采样是负债点（三条独立路径）｜三处分歧落进算子｜相术与外应反复落单。

**② 我套上去的**：
- "硬核 vs 参数"这个二分是**造的框** —— 只证明了"三处分歧落在算子里"，**没证明"其余全同"**
- "采样器配置决定流派分界"是**归纳**，而十线样本本就偏时间系（存在取样偏差）
- 把"读数＝受约束检索"与"定期＝键锁匹配"合成"第五步只有一种产物形态"，**合并动作是后加的**
- 相术的"心田"层（能反向推翻符号结果）是真例外，**未被纳入统一结构**

**③ 可能巧合的**：12 成为总线很可能只是"一年十二个月"这一个来源被反复搬运，**不构成九重独立证据**。

**④ 最软 / 最容易被推翻的**：
- **最软**：「换锚型能答具体事」——它靠"同帧耦合"，而**同帧耦合在无反馈时不可验证**
- **最大杠杆**：总公理第 2 条。一条大样本、可复现、"同编码而吉凶分布与随机无异"的观察 ⇒ **十线俱倒**

**⇒ 使用姿势：把这份地图当作"定位工具"，不是"真理"。它能告诉你一条断法站在哪里、边界在哪；它不能证明这套东西对不对。**
