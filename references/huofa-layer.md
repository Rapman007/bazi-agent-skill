# 活法层 —— 第二条线

> **来源**：2026-10-03 用户批评「你那个一点都不活，是死的。没有看气，没有看整体，没有去联想」后建立。
> 本层读法规格独立成文，不依赖任何外部档。

---

## 〇、为什么要单独一层

**子平格局线（格局 → 旺衰 → 用神 → 喜忌）只能输出「结构」**：哪里低洼、哪里陡、哪段多雨。
**它输出不了"象"，也落不下断语。** 用户对它的原话评价是「**死的**」。

**本层是另一条线：气 → 整体 → 取象 → 神煞 / 纳音 / 胎元。**
**而且锚也换了**：子平的锚是**日干**；纳音 / 胎元那一路的锚是**年命**和**胎**。

---

## 一、必跑脚本

```bash
python3 scripts/huofa_layer.py --pillars 甲子,丙寅,戊午,庚申 --lunar-month 11 --name 某人
```

输出：四柱纳音 / 首尾纳音关系 / 胎元 / 命宫 / 羊刃 / 空亡 / 天乙贵人 / **三合派生神煞逐支扫描** / 派生神煞有无。
**只出客观层，不含解读。** 给 `--json` 可得结构化结果。

> ⚠️ **两个必查的算错点**（脚本已处理，人工复核时也要盯）：
> 1. **空亡必须按「日柱完整干支」取旬**，不能只拿日支。例：壬子属**甲辰旬**（空寅卯），不是甲子旬。
> 2. **纳音五行 = 名称末字**（大驿土→土、覆灯火→火），不是首字。

## 二、五件工具与读法

### 2.1 气 —— 四层气

| 层 | 看什么 |
|---|---|
| **天气** | 年干、月干（上面是什么压在什么上） |
| **地气** | 四支（哪一行成了势，土是燥的还是湿的） |
| **身气** | 日主 + 坐支（他自己是什么、坐在哪一点上） |
| **四周气** | 财 / 官 / 印 / 食伤 各自在天上还是地下、有没有根 |

**产出**：一句画面 + 一条"极纯 / 极杂" + 一条"极寒 / 极暖" + **出口在哪**。

> 🔴 **硬规：分清「药」与「出口」。**
> **药是从外面调进来的（等运）；出口是盘里本来就有的（随时能用）。**
> 旧法常把这两件混成一句"喜火土"，于是断语全押在"等运"上。

### 2.2 象 —— 取象 → 成象 → 落象

沿用 `delivery-spec.md` §三 的三段式，但**本层的象要多走一步**：
**每个象后面必须接一句"它解释了旧法看不到的什么"。** 接不上 ⇒ 那是散文，删。

**本层最常用的四个取象入口**：
灯 / 木、草、根；水、潭、流；刀、刃、锁（羊刃）；山、门、地（艮坤）。

### 2.3 纳音 —— **本层最大增量**

- 四柱纳音 + **首尾关系**（年柱纳音 ↔ 时柱纳音：同五行？相生？相克？）
- **纳音可以与正五行相反**。经典例：正五行四支无火，而**年柱纳音 + 时柱纳音皆火** ⇒ 不是"无火"，是**火在两头**。
- 用法：
  - **首尾同五行** ⇒ 头尾同类，该五行"在两头兑现、中段缺位"
  - **首尾相克** ⇒ 开始与结束互相消耗
  - **纳音象**（海中金深藏 / 沙中金易见 / 覆灯火长明 / 霹雳火突发 / 炉中火在胎）

> 🔴 **硬规：纳音五行 ≠ 正五行。**
> 两套表的基数不同（30 vs 60），**没有通用翻译**（见 `framework-map.md` §二②）。
> **不得把纳音五行代进正五行的生克运算里。** 两者只能"并置对照"，不能"合并计算"。

### 2.4 胎元 · 命宫 —— **藏起来的那个位置**

- **胎元** = 月干进一位、月支进三位（脚本算）
- 用途：找**"不在明面四支上"的东西**。典型发现：**日干的天乙贵人在四支里一个都没有，却正好落在胎元支上** ⇒ **贵人在胎里，不在明处**。
- **命宫** = 寅起正月顺数至生月得 A，再自 A 起子时逆数至生时
- 用途：**第二个"暗位"**。常与胎元一起构成"明处没有、暗处有两处"的格局。

> 🔴 **硬规：胎元与命宫都是"确定性反推"**（由月柱/时辰唯一决定），
> **按 `framework-map.md` §二③ 判据一，它们不算"外部取数"** —— 它们不能用来回答"具体哪件事"，只能用来找"暗位"。

### 2.5 神煞派生 —— **三合四组是最大共用锚点**

**驿马 / 桃花 / 华盖 / 将星 / 劫煞 全部由三合四组派生**，不是五个独立的口诀：

| 局 | 驿马（长生之冲） | 桃花 | 华盖（末字） | 将星（中神） | 劫煞 |
|---|---|---|---|---|---|
| 申子辰 | 寅 | 酉 | 辰 | 子 | 巳 |
| 寅午戌 | 申 | 卯 | 戌 | 午 | 亥 |
| 巳酉丑 | 亥 | 午 | 丑 | 酉 | 寅 |
| 亥卯未 | 巳 | 子 | 未 | 卯 | 申 |

**读法三条**：
1. **按"每一支各自的局"判有没有落点**，不能按神煞名字一刀切（脚本已按此实现）。
2. **同一个字上压着几个神煞，比有几个神煞更重要。** 若羊刃 + 将星 + 天乙同落一位 ⇒ **象：刀、令牌、护符塞在同一个抽屉** ⇒ 一冲三动。
3. **"缺件"比"有件"更值得说**：无驿马 = 缺"走出去"的零件；无桃花 = 缺"主动外张"；无空亡 = 没有"反正这个不算"的地方。

> 🔴 **硬规：神煞是「附着层」，不是「力学层」。**
> 神煞**不能否掉冲刑合害这条力学事实**。
> 另：**神煞起法有版本冲突** —— 驿马/将星《三命通会》以**年支**起，清代改**日支**起。脚本逐支全列，**解读时须注明用的是哪一法**。

#### 🔴 已判错的两条（实盘核验 · **不要再犯**）

| 判法 | 状态 | 依据 |
|---|---|---|
| **「无驿马 ⇒ 不走广度路线 / 不动」** | ⛔ **降级为「不作独立断语」** | **实测反例：某盘四支无驿马，而现实是命主主动、高频社交——判错。** 同一盘，**紫微「禄马交驰」判"要动"是对的**。⇒ 神煞不能否掉力学事实 |
| **「某柱的力已经用掉」**（如"年柱的火炸过就没了"） | ⛔ **禁止** | 出过一次过判：把"火在两头"（位置读）升级成"头已烧完"（时间叙事）——**那一步没有任何盘面依据** |

> **反面：✅ 判法加强的一条**
> **「空亡 ⇒ 有靠之形、少靠之实」** —— 可用于独立断语。
> 实盘：某盘的两个印（年支、时支）**同时空亡** ⇒ 现实是"**有靠之形、无靠之实**"（有个依靠的样子，底子是空的），与 `shishen-xiang.md` 印条原文几乎逐字对上。

## 三、落到方向（用户高频需求）

**方向 / 路径匹配在允许输出范围内**（见 `delivery-spec.md` §六"能排 6 项"）。

### 梅花体用合参（把"象"落到"事"）

```bash
python3 -m skills.meihua-yishu.scripts.meihua_calc gregorian <年> <月> <日> <时>
```

1. **体卦 = "我"**；用卦 = "命"
2. **口诀**：「以体为主，以用为命……**体生者为子，体克者为财，生体者为父，克体者为官，扶体者为兄弟**」
3. 三个支点：
   - **体用生克**（用生体=得助最吉；体克用=可成但劳；体生用=泄气；用克体=受压；比和=顺）
   - **互卦 = 中段过程**；**变卦 = 结局**
   - **卦德**（震=动、艮=止、坤=承载、巽=入）解释力常强于五行
4. **交叉点**：**卦的"体"和八字的"唯一出口"，常指向同一个五行** —— 两条独立线撞在一起时，那才是可信的

> 🔴 **口径缺陷必须前置**：梅花时间卦**只用年支+农历月+农历日+时支**，
> 8 个字里只用了 2 个 ⇒ **它不是八字的忠实翻译，置信度低于八字档，不得覆盖已登记断语。**

## 四、⭐ 泛化检验（**本层唯一的自证方法 · 必做**）

> **定稿依据**：「**你给我怎么看的，到时候其他人呢？都怎么看，知道不？**」

**这是对本层最要害的一问** —— 一套拿单一命主的盘练出来的说法，换了盘还成立吗？

**规程**：用 `huofa_layer.py` **对 ≥3 副非目标盘跑同一套算法**，逐项比对。

| 检查 | 通过标准 |
|---|---|
| 纳音 / 首尾关系 | 各盘不同（不得都是"首尾同五行"） |
| 胎元 / 命宫 | 各盘不同 |
| 派生神煞有无 | 各盘不同 |
| 缺件 | 各盘不同 |
| 写出的一句话画面 | **必须随盘变**；若雷同 ⇒ **套模板嫌疑成立，本套输出降级** |

> **这是反谄媚自检 D（盲审法）在本层的落地。只测"输出有没有随盘变"，不测"算得准不准"。**

## 五、与子平线的三处"不许圆"

| # | 冲突类型 | 处理 |
|---|---|---|
| 1 | **同一个五行，两线评价相反**（如"土"：子平＝官杀＝压力；梅花体用＝我所克＝财） | **并置，写明"两线维度不同，不做换算"** |
| 2 | **"能不能成"两说**（如子平＝取之力薄；体用＝体旺用囚可成） | 同上 |
| 3 | **本层内部矛盾**（如颐卦"由颐"＝靠外力 vs "体克用"＝靠硬拼） | **如实标出，不选边、不圆场** |

> **依据**：`falsifiable-protocol.md` 第四条（争议下断／不许"两种可能都有"）。
> **不得**用"各有千秋""维度不同"掩盖 —— 要写成"**A 说 X，B 说 Y，本档不选边，理由是……**"。

## 六、本层三条红线

1. **神煞不是力学。** 不许用"无驿马"否掉"丑未冲主动"这类冲刑合害事实。
2. **纳音不是正五行。** 不许把纳音五行代进生克运算。
3. **象不是断语。** 象法是表达层，按 `delivery-spec.md` 的双轨记账 —— **B 轨不入验证档、不计分**。
